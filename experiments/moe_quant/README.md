# MoE Quant Experiment Baselines

This directory contains lightweight baseline configs for the phased MoE quantization validation project.

## Files

- `phase1_fp_moe_baseline.json`
  - Floating-point MoE baseline for Phase 1 acceptance.
- `phase2_ternary_expert_baseline.json`
  - Ternary expert baseline for Phase 2 acceptance.

These files are intended as stable experiment anchors for later training and evaluation scripts.
